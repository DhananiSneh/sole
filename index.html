One founder

Five teams run the company.

You bring a lead. Desk opens it. Sales writes the offer. Studio builds the page. Books writes the invoice. Review can hold the folder. You send it.

  1. Desk Opens the lead and writes the handover.
  2. Sales Decides if the work fits, then prices it.
  3. Studio Builds the one-page site the client opens.
  4. Books Invoices the offer price, and no other number.
  5. Review Checks the folder without asking the writer.
node src/cli.js "A bakery needs a one-page website. Budget 40000 INR. Due Friday."

Sales, Studio, and Books use Grok when XAI_API_KEY is set. Without a key, the same path runs locally. Source
